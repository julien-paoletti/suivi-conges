Comment utiliser l'application ?

📅 Sélectionner des jours de congés

  • Clic simple : Cliquez sur un jour pour le marquer comme congé
  • Cycle de couleurs : Chaque clic change le type de congé
    • 1er clic : Congés Annuels (vert)
    • 2e clic : RTT (bleu)
    • 3e clic : Autres (orange)
    • 4e clic : Retour à l'état normal
  • Glisser-déposer : Maintenez le bouton de la souris enfoncé et glissez sur plusieurs jours pour les sélectionner rapidement

🗑️ Réinitialiser

  • Par mois : Cliquez sur le bouton ✕ en haut à droite de chaque mois

🏫 Vacances scolaires

  • Sélectionnez votre zone (A, B ou C) pour afficher les vacances scolaires
  • Les jours de vacances apparaissent avec un contour violet
  • Utilisez l'icône ? pour savoir quelle zone choisir

💾 Sauvegarder et exporter

  • Sauvegarde automatique : Vos congés sont automatiquement enregistrés dans votre navigateur
  • Exporter : Cliquez sur "Exporter JSON" pour télécharger une copie de vos données
  • Importer : Cliquez sur "Importer JSON" pour restaurer des données précédemment exportées

🌓 Thème

  • Cliquez sur l'icône ☀️/🌙 en haut à droite pour basculer entre thème clair et sombre

ℹ️ Informations utiles

  • Les jours fériés sont affichés en rouge et non modifiables
  • Les weekends apparaissent en gris
  • Le jour actuel est entouré en bleu
  • Les numéros de semaine (S) sont affichés à gauche selon la norme ISO 8601
